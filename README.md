# 🧮 S3 Discrete Math Solver

An interactive **Discrete Mathematics Solver** built with Python and Streamlit for solving common problems from discrete mathematics.

## 🚀 Live Demo

**Live Application:**
https://s3-discrete-math-solver.onrender.com/

## 📂 GitHub Repository

**Source Code:**
https://github.com/sathwik-svg/s3-discrete-math-solver

## 📚 Features

### 🔢 Set Operations

* Union
* Intersection
* Difference
* Symmetric difference
* Subset checking

### 🔀 Permutations & Combinations

* Calculate `nPr`
* Calculate `nCr`
* Input validation for `n` and `r`

### ➗ GCD & LCM

* Calculate GCD of multiple numbers
* Calculate LCM of multiple numbers

### 🔗 Relations

* Enter ordered pairs
* Calculate domain
* Calculate range
* Check reflexivity
* Check symmetry

### ✖️ Cartesian Product

* Generate Cartesian product of two sets
* Calculate the size of the Cartesian product

### 🧠 Boolean Logic

* AND
* OR
* NOT
* XOR
* Implication
* Biconditional

### 📊 Truth Tables

Generate truth tables for common Boolean operations.

### 🕸️ Graph Theory

* Number of vertices
* Number of edges
* Maximum edges in a simple undirected graph
* Basic graph validity checking

## ⚙️ Run Locally

Clone the repository:

```bash
git clone https://github.com/sathwik-svg/s3-discrete-math-solver.git
cd s3-discrete-math-solver
```

Create a virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

Open:

```text
http://localhost:8501
```

## ☁️ Deployment

This project is deployed on **Render** using the following command:

```bash
streamlit run app.py --server.port $PORT --server.address 0.0.0.0 --server.headless true --server.enableCORS false --server.enableXsrfProtection false
```

Build command:

```bash
pip install -r requirements.txt
```
